# Project2 Admin Dashboard

This is a responsive admin dashboard project created in the project2 folder.

## Structure
- pages/index.html — dashboard interface
- style/style.css — responsive layout and styling
- script/app.js — mobile sidebar toggle behavior

## Usage
Open project2/pages/index.html in your browser.

## Notes
- The layout is built with semantic page sections and accessible sidebar toggling.
- The mobile breakpoint collapses the sidebar and enables a menu button.
- No additional dependencies are required beyond Font Awesome icons.
