## About the Project

`marque-mernStack` is a web development learning repository built around the basics of modern front-end development and the broader MERN stack journey.

The repository is organized into separate folders for different topics, making it easier to study one area at a time and gradually move toward complete projects.

This kind of structure is especially helpful for:
- practicing HTML and CSS separately
- learning JavaScript in isolation
- building projects with increasing complexity
- keeping learning material organized in one place

---

## What This Repository Contains

Based on the current repository structure and language composition, this repository mainly contains:

- **HTML files** for page structure and markup
- **CSS files** for styling and layout
- **JavaScript files** for interactivity and logic
- **Project folders** for real-world practice examples
- **VS Code configuration** for a better development setup

The repository is mainly front-end focused right now, but it can evolve into a more complete MERN learning resource later.
